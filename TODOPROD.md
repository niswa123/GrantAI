# 🚀 TODOPROD: GrantAI (Engineering Value & R&D Layer)

Мы переходим к полноценному продукту. Цель: построить систему, которая **автоматически извлекает инженерную работу (Jira, GitHub, Linear) в реальном времени, прогоняет её через AI-фильтр и конвертирует в финансовый актив (R&D Value).**

Это та самая "преждевременная инженерия", которая делает продукт настоящим технологическим стартапом.

---

## 🏗 Фаза 1: Инфраструктура и Архитектура (Background & Events)
Поскольку мы будем слушать вебхуки и тянуть много данных, нам нужна асинхронная архитектура.

- [x] **Настройка системы очередей (Background Jobs)**
  - Выбрать и внедрить инструмент (Inngest / BullMQ + Redis / Trigger.dev).
  - Настроить worker'ы для фоновой обработки задач (парсинг коммитов, вызов LLM).
- [x] **Проектирование расширенной схемы БД (Prisma)**
  - `Integration`: токены для Jira, GitHub, Linear.
  - `EngineeringEvent`: сырые логи (коммит, закрытый тикет, пулл-реквест).
  - `AnalyzedLog`: результат работы LLM (оценка неопределенности, новизны, сложности).
  - `DailyValueMap`: агрегированная R&D ценность по дням/командам.

## 🔌 Фаза 2: Data Ingestion (Интеграции)
Система должна забирать данные там, где работают инженеры.

- [x] **Модуль интеграции с GitHub / GitLab**
  - OAuth авторизация для подключения репозиториев.
  - Подписка на вебхуки (Push events, PR merged).
  - Фоновый парсинг diff'ов и описаний PR.
- [x] **Модуль интеграции с Jira / Linear**
  - OAuth авторизация.
  - Подписка на вебхуки (Task Closed / Done).
  - Извлечение описания задачи, времени (если есть) и комментариев.
- [x] **Universal Event Normalizer**
  - Микросервис/функция, которая приводит любой сырой лог (тикет или коммит) к единому формату `EngineeringEvent` перед отправкой в AI.

## 🧠 Фаза 3: AI Neural Processing (Движок оценки R&D)
Самое сердце системы. Фильтрация рутины от реального R&D.

- [x] **R&D Analyzer Pipeline (LLM)**
  - Асинхронный пайплайн: берет новый `EngineeringEvent`, отправляет в OpenAI/Anthropic.
  - **Prompt Engineering**: жесткие критерии оценки (1. Техническая неопределенность, 2. Новизна, 3. Инженерная сложность).
  - Возврат структурированного JSON:
    - `is_rd`: boolean
    - `confidence_score`: 0.0 - 1.0
    - `justification`: краткое обоснование для аудита
    - `complexity_weight`: вес сложности
- [x] **Auto-Tuning & Feedback Loop**
  - Интерфейс для пользователя: "Это не R&D" или "Это R&D" для дообучения/корректировки LLM.

## 💰 Фаза 4: Financial Aggregation Layer
Конвертация инженерной работы в деньги.

- [x] **Настройка Financial Engine**
  - Привязка зарплат (Salary Data) или рейт-карт (Hourly rates) к пользователям/командам.
  - Формула: `(Затраченное время / Вес задачи) * Часовая ставка * Confidence Score * Коэффициент налоговой льготы`.
- [x] **Real-time Aggregation**
  - Ежедневный расчет `Daily R&D Value Flow`.
  - Запись финансовых снапшотов (DailyValueMap), чтобы дашборд мог показывать красивые графики "€X earned today".

## 🖥 Фаза 5: WOW-Интерфейсы (Dashboard & UX)
Визуализация магии. Инженерия в реальном времени.

- [x] **Real-time Dashboard (Как на лендинге)**
  - Интеграция с WebSocket или Server-Sent Events (SSE) для "живого" обновления графика (появление новых логов).
  - График "Daily Value Tracked" (€).
  - Метрика "AI Confidence Score" (%).
- [x] **Лента Engineering Events (Live Feed)**
  - Стриминг входящих событий: "Тикет JIRA-123 закрыт → Оценка AI: 87% R&D → Добавлено €320".
- [x] **Настройки команд и проектов (Settings)**
  - Интерфейс для указания рейтов инженеров.
  - Управление скоупом интеграций (какие репозитории слушать).

## 📄 Фаза 6: Compliance & Audit Defense
Финал работы системы — генерация неуязвимого документа для налоговой.

- [x] **Claim Generator Engine**
  - Сбор всех `AnalyzedLog` за период (месяц/квартал/год).
  - Генерация связного, профессионального отчета на основе тысяч микро-логов.
  - Экспорт в PDF / DOCX с соблюдением форматов (например, для UK HMRC или US IRS).
- [x] **Traceability (След для аудитора)**
  - Возможность кликнуть на любую цифру в отчете и провалиться до конкретного коммита/тикета, который сгенерировал этот цент.
