# 5. БИЗНЕС-ЛОГИКА

## 5.1 Определение R&D проектов

Простейшая версия:

```
keywords = ["algorithm", "ai", "system", "platform", "data", "model"]

if description contains keywords:
  is_rd = true
  rd_score = 0.6–0.9
else:
  rd_score = 0.1–0.3
```

---

## 5.2 Определение R&D расходов

```
if expense.type in ["salary", "contractor"]:
  is_rd_related = true
else:
  false
```

---

## 5.3 Расчёт суммы

```
rd_expenses_total = sum(expenses where is_rd_related = true)

estimated_amount = rd_expenses_total * 0.2
```

(коэффициент конфигурируемый)

---

## 5.4 Расчёт rd_score компании

```
rd_score = average(project.rd_score)
```
