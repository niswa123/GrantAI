### 🎬 Installation Steps

<details open>
<summary><b>Step 1️⃣: Clone Repository</b></summary>

```bash
git clone https://github.com/niswa123/GrantAI.git
cd GrantAI
```

</details>

<details open>
<summary><b>Step 2️⃣: Install Dependencies</b></summary>

```bash
# Backend
cd backend
npm install

# Frontend (in new terminal)
cd frontend
npm install
```

</details>

<details open>
<summary><b>Step 3️⃣: Database Setup</b></summary>

```bash
cd backend

# Copy environment file
cp .env.example .env

# Edit .env and set your DATABASE_URL
# DATABASE_URL="postgresql://user:password@localhost:5432/grantai_db"

# Run migrations
npx prisma migrate dev

# Generate Prisma Client
npx prisma generate
```

</details>

<details>
<summary><b>Step 4️⃣: Configure Integrations (Optional)</b></summary>

<br/>

To enable GitHub and Jira integrations:

1. Create OAuth apps on GitHub/Jira
2. Add credentials to `.env`
3. Follow detailed guide: [SETUP_TUTORIAL_RU.md](./SETUP_TUTORIAL_RU.md) 🇷🇺

```env
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
JIRA_CLIENT_ID=your_jira_client_id
JIRA_CLIENT_SECRET=your_jira_client_secret
```

</details>

<details open>
<summary><b>Step 5️⃣: Launch Application</b></summary>

```bash
# Terminal 1 - Backend
cd backend
npm run start:dev

# Terminal 2 - Frontend
cd frontend
npm run dev
```

</details>

## 🔌 API

<div align="center">

### **RESTful API with JWT Authentication**

**Base URL:** `http://localhost:3000/api`

</div>

### 🔐 Authentication

All protected endpoints require JWT token in header:

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

<br/>

### 📍 API Endpoints

<details>
<summary><b>🔐 Authentication</b></summary>

```bash
POST   /auth/register          # Register new user
POST   /auth/login             # Login and get JWT token
GET    /auth/profile           # Get current user profile
POST   /auth/refresh           # Refresh JWT token
```

**Example:**
```bash
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"secure123","name":"John Doe"}'
```

</details>

<details>
<summary><b>🏢 Companies</b></summary>

### 🔄 Development Workflow

```bash
# 1️⃣ Fork the repository
# Click "Fork" button on GitHub

# 2️⃣ Clone your fork
git clone https://github.com/YOUR_USERNAME/GrantAI.git

git checkout -b feature/AmazingFeature

# 4️⃣ Make your changes
# ... code code code ...

# 5️⃣ Commit your changes
git commit -m 'Add some AmazingFeature'

# 6️⃣ Push to your fork
git push origin feature/AmazingFeature

# 7️⃣ Open a Pull Request
# Go to GitHub and click "New Pull Request"
```

<br/>

### 📝 Commit Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add new feature
fix: bug fix
docs: documentation changes
style: formatting, missing semicolons, etc
refactor: code refactoring
test: adding tests
chore: maintenance tasks
```

<br/>

### ✅ Pull Request Checklist

- [ ] Code follows the project's style guidelines
- [ ] Self-review of code completed
- [ ] Comments added for complex logic
- [ ] Documentation updated (if needed)
- [ ] No new warnings generated
- [ ] Tests added/updated (if applicable)
- [ ] All tests passing
- [ ] Branch is up to date with main
